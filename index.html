Панель редактирования

Введите пароль, чтобы менять товары

Пароль проверяется на сервере и в файлах сайта не хранится. Он же используется для публикации — вводить второй раз не придётся. Меняется в настройках Netlify (переменная ADMIN_PASSWORD).

Редактор каталога

Меняй товары, потом жми «Опубликовать на сайте» — остальное само

Настройки магазина

Куда сайт отправляет заказы. Как её получить — в файле google-apps-script.gs. Пока поле пустое, заказ просто показывает подтверждение (в таблицу не уходит).

Добавить товар

Если у товара есть опции — при клике «В корзину» покупатель выберет их в окошке. «Список» — выбор из вариантов (через запятую), «текст» — свободное поле.

Первое фото — обложка. Стрелками ‹ › меняй порядок, ✕ удаляет. Совет: для многих фото лучше вставлять ссылки (напр. с postimages.org / imgur), чтобы файл сайта не разрастался.

Необязательно. Впиши сколько физически лежит на полке — на карточке появится «Осталось N шт», и больше этого в корзину не положат. Дальше число уменьшается само с каждым заказом. Вписала новое число — счётчик обнулился (это и есть пополнение). 0 = распродано. Пусто — учёта нет.

Опубликовать изменения

Жми «Опубликовать» — правки появятся на сайте через несколько секунд. Сборка сайта не запускается, кредиты Netlify не тратятся.

Галочка нужна редко — она дополнительно коммитит каталог в репозиторий, а это уже запускает сборку и расходует кредиты. Для обычных правок оставляй её снятой.

Пока не нажмёшь «Опубликовать», изменения видишь только ты (они лежат черновиком в твоём браузере).
